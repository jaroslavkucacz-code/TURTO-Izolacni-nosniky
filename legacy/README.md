# Legacy

Tento adresář obsahuje pouze historické nástroje, které mají ještě konkrétní důvod zůstat v aktuální větvi.

## migration_v051

Jednorázový převod velmi staré lokální instalace TURTO v0.4.0 / v0.5.0 na GitHub základ 0.5.1.

Kořenový `00_INSTALOVAT_TURTO.bat` je pouze kompatibilní spouštěč tohoto převodu.

## Co už v aktuální větvi není

Staré samostatné HIT prototypy, jednorázové build fragmenty, balíčkové payloady a historické CI workflowy byly z aktuální větve odstraněny v úklidu 2.2.0.

Nejsou ztracené: zůstávají v Git historii a lze je dohledat v commitech před TURTO 2.2.0.
